The service

FindMySize gives clothing brands a way to recommend a size from a short video. A brand pays a monthly fee for unlimited size charts. A shopper uses the tool for free and needs no account.

Measurements are estimates

Every number is an estimate from a video. It is shown with the reading behind it so it can be checked. A brand is responsible for the size charts it types. We do not guarantee that a recommended size will fit.

Accounts
